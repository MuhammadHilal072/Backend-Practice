# Backend Practice

Node.js and Express practice from my web development journey.

## What's inside

| Folder         | Contents |
| `node-basics/` | Core Node.js practice: modules (`math.js`, `script.js`), `fruits/`, and small npm-package projects (`FigletDir`, `MyProject`, `random_words`) |
| `express-get-post/` | An Express app that handles GET and POST requests (`index.js`) |

## Tech
Node.js, Express, npm

## How to run
Each folder has its own dependencies:

    cd express-get-post
    npm install
    node index.js

Then open the port shown in the terminal (check the `listen` line in `index.js`).
